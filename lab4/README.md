# Lab 4

Run both suites from the repository root:

```powershell
powershell -ExecutionPolicy Bypass -File lab4/run-tests.ps1 -Suite all
```

The baseline suite compiles the exact `lab4-base:code/game.cpp` source generated by
`git show`, renaming only its `main` symbol in the test translation unit. The seam suite
compiles the current production source and supplies a deterministic `ScriptedFood`.
Generated executables and gcov files remain under the ignored `lab4/build/` directory.

Validated with MinGW GCC/gcov 6.3.0 on Windows. No external test dependency is required.
